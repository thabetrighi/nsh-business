# ADR-0002: المكتبات الأساسية

- **الحالة:** معتمد — 2026-11-10.

| الغرض | المكتبة | السبب (من Spikes M0) |
|---|---|---|
| قاعدة البيانات المحلية | `rusqlite` ≥ 0.41 (`bundled` أصلياً؛ `sqlite-wasm-rs` تلقائياً على الويب) | شيفرة واحدة لكل المنصات؛ FTS5؛ بحث 3 ms على 100k |
| تخزين الويب | `sqlite-wasm-vfs` (sahpool / OPFS) داخل Web Worker | ديمومة كاملة، باقٍ بعد إعادة تشغيل المتصفح، بيع 2.1 ms |
| إعدادات SQLite | WAL أصلياً، `synchronous=FULL` | 0.4 ms للبيع مع ضمان عدم فقد آخر عملية |
| المال | `i64` بأصغر وحدة (centimes) + رمز العملة | لا أخطاء تقريب |
| الكميات والنسب | `rust_decimal` | دقة عشرية للأوزان والوحدات |
| المعرّفات | `uuid` v7 | فريدة دون اتصال، مرتبة زمنياً |
| تخطيط نص المستندات | `cosmic-text` | تشكيل عربي + bidi + تقسيم أسطر |
| PDF | `krilla` | رموز دقيقة، خطوط مضمّنة جزئياً، نص قابل للنسخ |
| الطباعة الحرارية | ESC/POS نقطي `GS v 0` (شيفرتنا) | يعمل على أي طابعة دون دعم عربي |
| الخطوط | IBM Plex Sans Arabic (واجهة + مستندات)، رخصة OFL | عربي ولاتيني متناسقان، أرقام جدولية |

## قرار معماري مرتبط: وصول غير متزامن للبيانات
واجهات المستودعات في `nb-app` غير متزامنة. أصلياً: SQLite في خيط خلفي (`background`). ويب: Worker برسائل. الواجهة لا تُحجب أبداً.
