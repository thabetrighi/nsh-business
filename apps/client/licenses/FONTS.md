# Bundled fonts

All fonts are under the SIL Open Font License 1.1 (one license file per family here).

| Family | Files | Source | Notes |
|---|---|---|---|
| Cairo (default) | Regular, Medium, SemiBold, Bold | google/fonts `ofl/cairo` (variable) | Static instances made with fontTools `varLib.instancer` (slnt 0; wght 400, 500, 650 for SemiBold, 700). |
| Tajawal | Regular, Medium, Bold | google/fonts `ofl/tajawal` | Unmodified. |
| Almarai | Regular, Bold, ExtraBold | google/fonts `ofl/almarai` | Unmodified. |
| Readex Pro | Regular, Medium, SemiBold, Bold | google/fonts `ofl/readexpro` (variable) | Static instances (HEXP 0; wght 400–700). |
| IBM Plex Sans Arabic | Regular, Medium, SemiBold, Bold | IBM/plex | Unmodified (`IBM-Plex-OFL.txt`). |

Name tables of the instances were normalized so each family's weights group under one family name.
